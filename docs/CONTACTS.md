# Контакты из телефонной книги

Найденные знакомые хранятся на сервере и видны на всех устройствах: вкладка «Контакты» →
«Из телефона», имена из книги в списке чатов, статус в Настройках.

## PWA (сайт на телефоне) — основной вариант

Браузер не даёт сайту читать телефонную книгу сам, поэтому контакты добавляет человек:

- **Android (Chrome)** — «Выбрать из контактов»: системный выбор нескольких контактов
  (Contact Picker API).
- **iPhone и любое устройство** — «Загрузить контакты из файла»: файл `.vcf`
  («Контакты» → «Списки» → удерживать «Все контакты» → «Экспортировать», или icloud.com).
  Файл разбирается в браузере (`web/src/utils/vcard.ts`), на сервер уходят имена и номера.
- **Первое открытие на телефоне или планшете** — окно «Найти знакомых в Quazar?»
  (`ContactsPrompt`). Закрыли — те же кнопки в Настройках → «Контакты из телефона».
- Фонового обновления нет: новых знакомых человек добавляет так же, вручную. Импорт идёт в
  режиме `merge` — найденные добавляются к списку, а не заменяют его.

## Мобильное приложение (если будет собрано)

Код готов в `mobile/`, но нативных приложений пока нет.

1. **Первый вход в приложение** — окно «Найти знакомых в Quazar?». «Разрешить» → системный
   запрос доступа → сверка. «Не сейчас» → переключатель остаётся в **Профиле**.
2. **Дальше само**: при запуске и при каждом возвращении в приложение, если с прошлой сверки
   прошло больше 12 часов (`SYNC_INTERVAL_MS` в `mobile/src/store/contacts.ts`). Когда
   приложение закрыто, сверки нет: iOS не даёт регулярно запускаться в фоне.
3. **Выключили в профиле** — сверка прекращается, найденные удаляются с сервера.
4. Доступ забрали в настройках системы — в профиле подсказка и кнопка «Открыть настройки».

## Что уходит на сервер и что остаётся

- `POST /contacts/sync` — имена и номера (без фото, почты, адресов); `mode: "replace"` —
  книга целиком (приложение), `mode: "merge"` — часть книги (PWA). Сервер
  нормализует российские номера, ищет пользователей Quazar и **сохраняет только найденных**
  (`user_contacts`: кто, кого нашёл, имя из книги). Остальные номера не записываются.
  Повторная сверка заменяет список — удалённые из книги пропадают.
- Не чаще 10 сверок в час на пользователя (`429`), до 5000 контактов и 10 номеров у каждого.
- `GET /contacts` — найденные, время последней сверки; `DELETE /contacts` — стереть.
- После сверки сервер шлёт событие `contacts_updated` — открытый веб обновляет список сам.

## Нативная настройка мобильного приложения (один раз, после `npx react-native init`)

Библиотека — `react-native-contacts` 8.0.4.

**Android** — `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.READ_CONTACTS" />
```

**iOS** — `ios/<App>/Info.plist`, затем `cd ios && pod install`:

```xml
<key>NSContactsUsageDescription</key>
<string>Quazar найдёт среди ваших контактов тех, кто уже пользуется мессенджером. Номера не сохраняются.</string>
```

Без этой строки iOS закроет приложение при запросе доступа.
