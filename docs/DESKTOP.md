# Quazar Desktop: закрытое тестирование

## Общая кодовая база

`web/src` — единственный интерфейс для сайта, Windows и macOS. `desktop/scripts/prepare-renderer.cjs` собирает его через обычный Vite build и включает результат в Electron. Изменения UI и продуктовой логики не дублируются. Источник номера версии — `web/package.json`; подготовка автоматически синхронизирует desktop package и lockfile.

`desktop/src` содержит только интеграцию с ОС: окно, трей, уведомления, выбор экрана, возврат из системного браузера и обновления. Веб работает без preload-моста. Дополнения для платформ находятся в `web/src/platform`.

## Сборка

Требуются Node.js 22.12+ и npm. На Mac также нужны Xcode Command Line Tools.

```sh
npm ci --prefix web
npm ci --prefix desktop
npm test --prefix desktop
npm start --prefix desktop
```

Установщики:

```sh
npm run build:mac --prefix desktop
npm run build:win --prefix desktop
```

Полноценную Windows-сборку следует выполнять на Windows. Workflow `.github/workflows/desktop.yml` собирает Windows x64, macOS arm64 и macOS x64 на соответствующих GitHub-hosted runners, запускает тесты и сохраняет установщики как Actions artifacts на 14 дней. Workflow запускается вручную, для main и веток `desktop/**`; серверный production-деплой остаётся отдельным процессом. Публикация установщиков для скачивания без авторизации выполняется отдельным workflow, описанным ниже.

Файлы появляются в `desktop/release/`. Windows — NSIS `.exe` для текущего пользователя, Mac — `.dmg` и `.zip`. Профиль хранится отдельно от программы, поэтому замена приложения не удаляет данные. Все тестовые версии используют один appId `ru.quazar.messenger` и стабильный каталог `Quazar` в системном appData.

## Скачивание без авторизации через GitHub Releases

`.github/workflows/desktop-release.yml` запускается при отправке тега `desktop-v<версия>-pilot.<номер>`. Он берёт уже собранные установщики из успешного desktop CI, указанного в `.github/desktop-release.json`, проверяет исходный коммит и отсутствие изменений кода приложений относительно него, затем публикует три установщика и `SHA256SUMS.txt` в отдельном Pre-release. Для публикации используется краткоживущий `GITHUB_TOKEN` с правом записи релиза; личный токен не требуется.

Перед следующим выпуском обновите version/run_id/source_sha в JSON на новую полностью успешную сборку и отправьте новый тег с тем же номером версии, что в web/package.json. Старый релиз не перезаписывается. Обычные коммиты и ветки сами по себе не публикуют установщики.

Первый пилот: `desktop-v0.19.2-pilot.1`. Прямые ссылки имеют вид `https://github.com/Balastov/Quazar-Messager/releases/download/desktop-v0.19.2-pilot.1/Quazar-0.19.2-win-x64.exe`, а для Mac — `Quazar-0.19.2-mac-arm64.dmg` и `Quazar-0.19.2-mac-x64.dmg` в том же релизе. Эти файлы не требуют входа в GitHub и не имеют 14-дневного срока Artifacts. Они доступны, пока релиз и файлы не удалены.

Публикация в Releases даёт ссылки на установщики и служебные файлы updater. Затем workflow проверяет SHA-512 всех файлов из метаданных и передаёт небольшой манифест по SSH с закреплённым ключом хоста. Сервер скачивает пакеты напрямую с GitHub по HTTPS в несколько потоков, умеет продолжать прерванные загрузки и сверяет SHA-256 каждого файла. После полной проверки атомарно обновляются `/desktop-updates/<платформа>-<архитектура>/`: сначала пакеты, затем метаданные. Повтор публикации идентичен и безопасен, понижение версии и замена байтов существующего установщика запрещены. Личный токен GitHub для клиентов не используется.

## Первый запуск и фон

В веб-версии кнопка «Скачать десктоп версию» находится на приветственном экране входа, в боковой панели и настройках. ОС определяется через доступную информацию браузера с резервным чтением user agent. Для Windows используется прямая ссылка на EXE; для Mac предлагаются оба процессора, поскольку строка `MacIntel` не гарантирует реальный Intel. На телефонах и планшетах, включая iPad в режиме настольного сайта, кнопка называется «Скачать мобильное приложение» и открывает заглушку «Мобильное приложение почти готово, ожидайте уведомление». Автоматического предложения на мобильных устройствах нет. На других настольных ОС список компьютерных сборок открывается вручную. В Electron кнопки и предложение скрыты.

Автоматическое предложение появляется через 20 секунд после входа только на Windows/macOS, в активном окне, вне звонка/комнаты, других диалогов и редактирования текста. При необходимости ждёт освобождения интерфейса. «Позже» откладывает его на 7 дней, «Не хочу» — на 30; «Да» и галочка «Больше не спрашивать» отключают автоматические предложения. Постоянная кнопка остаётся доступной. Выбор относится к текущему браузеру; при блокировке storage запоминается до закрытия страницы.

Под номером версии в боковой навигации на Windows/macOS находится компактная зелёная кнопка. В десктопном приложении «Обновить» появляется только после обнаружения более новой версии штатным updater. Номер установленного приложения берётся из Electron. В Windows кнопка недоступна, пока фоновая загрузка не завершена; после нажатия установка учитывает активные звонки. На Mac кнопка открывает скачивание DMG для ручной установки. Закрытие всплывающего предложения обновиться не скрывает кнопку под версией.

В вебе «Скачать» показывается только когда опубликованная десктопная версия новее версии загруженной веб-страницы. Метаданные читаются с `/desktop-updates/` без кэша при открытии страницы, каждые пять минут, при восстановлении сети и возвращении во вкладку; для Mac ожидается публикация обеих архитектур с одной версией. Ссылки строятся на нашем домене и не берутся из произвольных полей YAML. При одинаковых версиях кнопка под номером скрыта; обычное скачивание остаётся на странице входа и в настройках.

Нажатие «Скачать» пробует открыть `quazar-desktop://app/update`. Обработчик в приложении проверяет обновления, открывает окно и устанавливает найденную сборку Windows, если нет активного разговора; Mac открывает свой DMG для ручной установки. Холодный запуск использует результат штатной стартовой проверки. Повторные команды объединяются. Маршрут не принимает параметры, URL загрузки или данные авторизации. Эта команда появится у установленных клиентов после обновления оболочки; прежние версии могут только открыть окно.

Браузер не предоставляет надёжной проверки наличия приложения: системный запрос разрешения или отказ пользователя неотличимы от некоторых сценариев запуска. Если вкладка остаётся видимой и активной четыре секунды, начинается скачивание Windows-сборки; на Mac предлагается выбор процессора. Переключение фокуса отменяет автоматический переход, но диалог сохраняет прямые ссылки на последнюю опубликованную сборку. Закрытие диалога отменяет ожидающий переход.

Указатель на доступные установщики находится в `web/src/platform/desktopDownloads.ts`. При публикации следующей десктопной версии обновляйте там номер и тег уже опубликованного релиза. Номер сайта может отличаться: ссылки должны вести на существующие установщики, а не на ещё не опубликованную сборку.

Крестик скрывает окно, процесс остаётся в трее/строке меню и получает сообщения через WebSocket. Полное завершение — «Завершить Quazar». При активном разговоре спрашиваем подтверждение выхода. Автозапуск при входе в ОС пока не включается.

Desktop — новое устройство: сначала войдите звонком и при необходимости восстановите свой существующий ключ шифрования через штатный интерфейс. Браузерный профиль автоматически не импортируется; ключ аккаунта не перезаписывается.

Для микрофона, камеры и демонстрации потребуются обычные разрешения ОС. На Windows выбор источника делает отдельное окно с миниатюрами. Передача звука в нём явно обозначает захват всего системного звука; звук одного окна отдельно не обещается. На Mac используется системный picker, где он доступен; доступность системного звука проверяется на реальной версии macOS. Возврат из сна переподключает WebSocket.

## Вход через Яндекс

Desktop открывает системный браузер с `client=desktop` и challenge от случайного секрета устройства. Backend возвращает одноразовый код по `quazar-desktop://auth/yandex`; сессию в URL не передаёт. Обмен и регистрация требуют verifier устройства. Подтверждение важных действий через Яндекс также привязано к этому секрету. Привязка Яндекса по-прежнему требует подтверждённого телефона и свежего доказательства личности.

Для этого необходима новая версия backend из этой ветки. Адрес callback у Яндекса остаётся `https://quazar-msg.ru/api/auth/yandex/callback`. Настройка самого Яндекс OAuth в production ещё не выполнена: пока провайдер выключен, кнопка не показывается.

## Обновления

Приложение проверяет обновления при новом запуске процесса, каждые 30 минут и после сна. На Windows отдельное окно проверки/загрузки предшествует открытию интерфейса: найденная версия скачивается полностью, устанавливается без мастера установки и автоматически запускает приложение заново. Пропустить известное обновление нельзя, в том числе после ошибки загрузки; можно повторить попытку или завершить программу. Если сеть недоступна и о новой версии ничего не известно, можно явно продолжить без проверки. На Mac проверка остаётся автоматической, а установка — ручной: приложение открывается и предлагает DMG.

Во время работы Windows-обновление скачивается в фоне и предлагается кнопка перезапуска. Установка запрещена во время личного звонка, подключения или нахождения в комнате. Обычное скрытие/восстановление окна из трея не считается новым запуском и не прерывает разговор. «Проверить обновления» доступно из меню приложения и трея. В старой тестовой версии 0.19.2 первоначальный переход запускается этой кнопкой или фоновой проверкой; обязательная стартовая установка работает начиная с 0.20.0.

Каналы разделены:

- `https://quazar-msg.ru/desktop-updates/win-x64/`
- `https://quazar-msg.ru/desktop-updates/mac-arm64/`
- `https://quazar-msg.ru/desktop-updates/mac-x64/`

В каждый каталог помещаются файлы соответствующего Actions artifact: сначала установщики/архивы и `.blockmap`, затем атомарной заменой `latest.yml` (Windows) или `latest-mac.yml` (Mac). Не удаляйте предыдущие установщики, пока их может скачивать пользователь. Номер должен быть выше установленного. Разделение каталогов исключает перезапись Mac-метаданных другой архитектурой.

Production compose монтирует `/opt/quazar/desktop-updates` в web только для чтения. nginx отдаёт отсутствующие файлы как 404, не подменяя их SPA-страницей, и требует проверки актуальности метаданных. Реальные файлы сборок в git не хранятся.

CI Windows устанавливает отдельное одноразовое приложение 0.0.1, предоставляет ему локальный тестовый feed 0.0.2 и проверяет автоматическую установку, перезапуск и сохранение профиля без входа в живые аккаунты. Дополнительно проверяются стартовое окно на трёх ОС и отказ установки во время разговора. На пользовательских компьютерах остаются проверки поведения антивируса, разрешений ОС и реальных разговоров.

## Ограничения закрытого пилота

- Сертификаты издателя, Apple Developer Program и нотарификация намеренно отложены. Тестовые сборки могут показывать предупреждения ОС. Защиты системы автоматически не отключаем.
- Mac-сборка имеет локальную ad-hoc подпись для запуска Electron, но это не Developer ID. Поэтому Mac только обнаруживает новую версию и предлагает скачать DMG для ручной замены. Автоматическая установка Mac до следующего этапа выключена.
- Windows-тестовые пакеты не имеют удостоверенной подписи издателя. Updater использует HTTPS и проверку целостности пакетов; публичное распространение требует настройки доверенной подписи и проверки её обновления.
- Нельзя считать пройденными реальные звонки, системный звук, OS-уведомления и обновление установщика только по результатам сборки или unit-тестов. Нужны проверки на обоих типах Mac и Windows.

## Порядок следующих проверок

1. Установить пакет на Windows и Mac; проверить вход звонком и перенос существующего ключа. Никаких платных проверочных звонков автоматически в тестах не отправляется.
2. Проверить 1:1, Звёзды, отправку вложений, входящий звонок и уведомление при скрытом окне. Проверить фокус окна и открытие нужного чата/комнаты по уведомлению.
3. Проверить микрофон, камеру, демонстрацию экрана/окна со звуком и без, управление громкостью, fullscreen, выход из сна.
4. Опубликовать две тестовые версии: проверить Windows-переход, сохранение профиля, отказ установки во время разговора, обрыв загрузки и недоступный сервер. На Mac проверить ручную замену без потери данных.
5. Подключить доверенные подписи, нотарификацию и затем полноценно проверить автоматическую установку Mac. Магазины для прямой раздачи не обязательны.
