# Файлы: в чатах и Спутниках, раздел «Файлы» Звезды

Любой файл до **50 МБ**: «+» → «📎 Файл», перетаскивание в окно чата или Спутника, вставка из буфера.
Картинки (JPEG, PNG, GIF, WebP), перетащенные или вставленные, уходят как фото со сжатием
(см. `docs/IMAGES.md`); выбранные через «Файл» уходят как есть, без сжатия.

## Чаты (личные, группы, «Избранное»)

Так же, как фото: файл шифруется на устройстве случайным ключом (NaCl secretbox), шифротекст
уходит на `POST /chats/{id}/attachments`, а в чат — сообщение `FILE1:{"id","key","name","mime","size"}`.
В личных чатах это сообщение зашифровано E2E: сервер не видит ни содержимого, ни названия файла.
Храним **30 дней** (`ATTACHMENT_TTL_DAYS`), как фото; потом в чате «Файл удалён — они хранятся 30 дней».

Скачивание расшифровывает файл в браузере и отдаёт его «Сохранить как» с типом
`application/octet-stream`: присланный HTML не откроется как страница. Пересылка заново шифрует
файл для другого чата. В профиле собеседника — вкладка «Файлы».

Мобильное приложение пока показывает плашку «📎 название · размер — скачайте в веб-версии».

## Спутники

В Звёздах нет сквозного шифрования (как и у текста Спутников), поэтому файл лежит на сервере как есть —
так работают поиск по названию и превью картинок.

- `POST /stars/{star}/channels/{channel}/files?name=…` — тело запроса — сам файл, `Content-Type` — его тип.
  Потом файл уходит в сообщении: `POST …/messages` с `file_id` (текст — необязательная подпись).
- `GET /stars/{star}/files?q=&kind=all|images|docs&channel_id=&before=` — раздел «Файлы».
- `GET /stars/{star}/files/{id}` — только участникам. Картинки отдаются как картинки (для превью),
  всё остальное — `application/octet-stream` с `Content-Disposition: attachment` и `nosniff`.

Хранятся, **пока живо сообщение**: удалили сообщение (или его ветку, Спутник, Звезду) — файл стирается
с диска. У Звезды общий лимит **5 ГБ** (`STAR_FILES_QUOTA_MB`), занятое место видно внизу раздела
«Файлы». Загруженное, но не отправленное, удаляется через сутки.

## Раздел «Файлы» (📁 в колонке каналов)

Все файлы Звезды, свежие сверху: поиск по названию, фильтр «Документы / Картинки», фильтр по Спутнику,
«Скачать» и «В Спутник».

## Диск и nginx

| Что | Где |
|---|---|
| Файлы чатов | `MEDIA_ROOT/attachments/<id>` (шифротекст) |
| Файлы Спутников | `MEDIA_ROOT/star_files/<id>` |
| Лимит запроса | 50 МБ + 40 байт; nginx — `client_max_body_size 52m` (deploy-скрипт выставляет сам) |
| Свободное место | при остатке меньше `MEDIA_MIN_FREE_MB` загрузка отвечает `507` |
| Уборка | раз в час, вместе с вложениями чатов |
