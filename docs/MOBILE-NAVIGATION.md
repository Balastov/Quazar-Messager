# Мобильный возврат и время в списке чатов

На мобильных экранах чата, Спутника/комнаты, ветки и участников доступен свайп вправо для возврата. Стрелка «назад» остаётся и вызывает то же действие. Во вложенных экранах закрывается только верхний: ветка → Спутник → список каналов.

Жест начинается в области содержимого. Поля ввода, кнопки, ссылки, изображения, видео, код, диалоги и горизонтально прокручиваемые области не перехватываются. Вертикальная прокрутка, выделение текста, мультитач, свайп влево и короткое движение не вызывают возврат. При смене экрана или размера окна незавершённый жест отменяется. При системном уменьшении движения анимация отключается, сам жест продолжает работать.

Пока пользователь тянет экран, виден сдвиг к предыдущему экрану; недостаточное движение возвращается на место. По умолчанию у оболочки нет transform, чтобы не менять позиционирование фиксированных дочерних элементов. Touchmove отменяется только после определения горизонтального намерения; touchend отменяет совместимый клик после жеста.

В списке чатов показывается дата последнего сообщения по местному календарю устройства:

- Сегодня: `14:25`.
- Вчера: `вчера 14:25`.
- Раньше: `05.11.2026`.

Сравниваются календарные границы, а не интервалы по 24 часа. В полночь и при возвращении в окно подписи обновляются. Если сообщений нет, время создания чата не выдаётся за время последнего сообщения.

Проверки: `npm test` и `npm run build` из `web`; серверные счётчики — `tests.test_chat_features`. Сквозной сценарий с настоящим сенсорным вводом: `BROWSER_TEST_CASE=navigation backend/.venv/bin/python -B desktop/test/run-device-pairing.py` из корня после сборки веба. Он использует временную PostgreSQL, синтетические аккаунты и изолированный профиль Chromium; на Linux нужен `xvfb-run -a`.
