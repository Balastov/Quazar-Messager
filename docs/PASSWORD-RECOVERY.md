# Пароли и ручное восстановление доступа

На экране входа есть кнопка «Забыл пароль». Пользователь указывает никнейм
(можно с `@`, регистр не важен) либо номер телефона аккаунта.
Для существующего активного аккаунта создаётся обращение типа «Ошибка»
в Чёрной дыре с указанным логином и отметкой об отправке без авторизации.
Сообщение создаёт система: оно не доказывает, что заявку отправил владелец.
Повторные обращения объединяются, пока предыдущая заявка открыта.
Ответ на экране одинаков для найденного и неизвестного аккаунта;
число запросов с одного IP ограничено.

Владелец ресурса с доступом к Чёрной дыре открывает обращение,
проверяет личность заявителя привычным способом, вводит новый пароль
и повторяет его. Кнопка «Назначить новый пароль» сохраняет хэш пароля,
закрывает заявку и записывает время и администратора, выполнившего действие.
Готовую заявку нельзя использовать повторно. Обычные обращения типа «Ошибка»
не дают возможности назначить пароль.

Пароль передаётся пользователю администратором вне Quazar.
В обращение и сообщения поддержки сам пароль не записывается.
Пользователь может войти по номеру телефона и новому паролю,
затем заменить его в настройках.

В настройках «Вход в аккаунт» кнопка «Изменить пароль» открывает три поля:
старый пароль, новый пароль и повтор нового. Неверный старый пароль
оставляет форму открытой. Для аккаунта без пароля сохраняется существующее
подтверждение через Яндекс ID перед первым назначением пароля.
В мобильном клиенте восстановление доступно на экране входа,
а смена существующего пароля — в профиле.

Новый пароль должен содержать минимум 8 символов, не состоять только
из пробелов и занимать не более 72 байт UTF-8 (ограничение bcrypt).
После изменения сервер перестаёт принимать старые HTTP/WS токены
и закрывает подключённые WebSocket-сессии. При самостоятельной смене
текущий клиент получает свежий токен и продолжает работу.
Открытая заявка восстановления при этом автоматически завершается.
Ключи сквозного шифрования, зашифрованная резервная копия и привязка
Яндекс ID при смене пароля не изменяются.

Поля для восстановления и даты смены пароля добавляются при запуске
сервера через существующий механизм идемпотентных миграций.
