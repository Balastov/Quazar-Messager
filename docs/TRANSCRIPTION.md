# Расшифровка голосовых

В вебе и оболочках, использующих веб-интерфейс, под голосовым появляется «Расшифровать»,
если backend настроен. По нажатию пользователь подтверждает отправку выбранной записи
в Cloudflare. Клиент расшифровывает вложение, передаёт звук авторизованному backend,
backend вызывает Whisper Large V3 Turbo с `language=ru`, `task=transcribe`, `vad_filter=true`.
Ключ вложения не отправляется. Текст может содержать ошибки.

Аудио становится доступно backend и Cloudflare на время обработки. Вложения по-прежнему
хранятся зашифрованными; исходный звук и FLAC удаляются из временного каталога после
подготовки. Текст на сервере не сохраняется. Он кешируется в памяти вкладки, отдельно для
каждого пользователя и вложения; выход очищает кеш. Перезагрузка вкладки или другое
устройство потребует нового запроса. Расшифровки не публикуются в чат автоматически.

## Настройка сервера

В `/opt/quazar/.env.prod`:

```dotenv
CLOUDFLARE_ACCOUNT_ID=account_id_из_32_шестнадцатеричных_символов
CLOUDFLARE_API_TOKEN=секретный_токен
CLOUDFLARE_ASR_MODEL=@cf/openai/whisper-large-v3-turbo
TRANSCRIPTION_USER_MINUTES_PER_DAY=30
TRANSCRIPTION_TOTAL_MINUTES_PER_DAY=180
```

Токен: Workers AI Read и Edit только для нужного аккаунта. Секреты не коммитить.
Переменные передаются в контейнер через `docker-compose.prod.yml`. После получения
нового кода нужно пересобрать backend и web, сохранив остальные работающие сервисы:

```bash
cd /opt/quazar
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build --no-deps backend web
```

При старте backend создаёт таблицу `transcription_usage`. Отдельная миграция не нужна.
Образ backend уже включает ffmpeg/ffprobe для проверки звука и преобразования в FLAC.
Для локального backend они должны быть установлены в системе.

## Ограничение расходов

- Только авторизованный участник чата и существующее отправленное вложение.
- До 5 МБ исходного звука и 10 минут на запрос. Длительность проверяется по декодированному
  звуку, а не по полям клиента или заголовку контейнера.
- По умолчанию 30 минут/сутки на пользователя и 180 минут/сутки на весь Quazar.
- Дополнительно максимум 100 запросов/сутки на пользователя и 1000 на весь Quazar.
- Сутки — UTC. Счётчики хранятся в PostgreSQL, резервируются атомарно, не сбрасываются
  перезапуском backend. Нулевой/отрицательный лимит минут запрещает запросы.
- Попытка вызова Cloudflare учитывается даже при ошибке: провайдер мог обработать звук
  до разрыва связи. Автоматических повторов нет.

Это ограничения приложения, а не гарантия попадания в бесплатную квоту Cloudflare:
она общая с другими моделями аккаунта. Статистику смотреть в Workers AI dashboard.
На бесплатном плане Cloudflare при исчерпании квоты запросы отклоняются.

## Проверка

Войти в веб, открыть голосовое на русском, нажать «Расшифровать», подтвердить отправку.
Текст появится под волной. Повторно открыть то же голосовое в этой вкладке — результат
берётся из памяти без повторного обращения к Cloudflare.
Если ключей нет, кнопка скрыта; при ошибке или лимите показывается сообщение и возможность
повторить вручную. Эта интеграция относится к голосовым сообщениям чатов; записи встреч
и отдельный React Native клиент требуют отдельного подключения. Одновременно один процесс
backend декодирует не больше двух записей.

Документация: https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/
