# Расшифровка голосовых

В вебе и оболочках, использующих веб-интерфейс, под голосовым появляется «Расшифровать»,
если backend настроен. По нажатию пользователь подтверждает отправку выбранной записи
в Cloudflare. Клиент расшифровывает вложение, передаёт звук авторизованному backend,
backend вызывает Whisper Large V3 Turbo с `language=ru`, `task=transcribe`, `vad_filter=true`.
Ключ вложения не отправляется. Текст может содержать ошибки.

Аудио становится доступно backend и Cloudflare на время обработки. Вложения по-прежнему
хранятся зашифрованными; исходный звук и FLAC удаляются из временного каталога после
подготовки. Текст на сервере не сохраняется. Он кешируется в памяти вкладки, отдельно для
каждого пользователя и вложения; выход очищает кеш. Перезагрузка вкладки или другое
устройство потребует нового запроса. Расшифровки не публикуются в чат автоматически.

## Настройка сервера

В `/opt/quazar/.env.prod`:

```dotenv
CLOUDFLARE_ACCOUNT_ID=account_id_из_32_шестнадцатеричных_символов
CLOUDFLARE_API_TOKEN=секретный_токен
CLOUDFLARE_ASR_MODEL=@cf/openai/whisper-large-v3-turbo
TRANSCRIPTION_USER_MINUTES_PER_DAY=100
TRANSCRIPTION_TOTAL_MINUTES_PER_DAY=180
```

Токен: Workers AI Read и Edit только для нужного аккаунта. Секреты не коммитить.
Переменные передаются в контейнер через `docker-compose.prod.yml`. После получения
нового кода нужно пересобрать backend и web, сохранив остальные работающие сервисы:

```bash
cd /opt/quazar
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build --no-deps backend web
```

При старте backend создаёт таблицу `transcription_usage`. Отдельная миграция не нужна.
Образ backend уже включает ffmpeg/ffprobe для проверки звука и преобразования в FLAC.
Для локального backend они должны быть установлены в системе.

## Ограничение расходов

- Только авторизованный участник чата и существующее отправленное вложение.
- До 5 МБ исходного звука и 10 минут на запрос. Длительность проверяется по декодированному
  звуку, а не по полям клиента или заголовку контейнера.
- По умолчанию 100 минут/сутки на пользователя и 180 минут/сутки на весь Quazar.
- Дополнительно максимум 100 запросов/сутки на пользователя и 1000 на весь Quazar.
- Суперпользователь не ограничен дневными минутами или числом запросов Quazar, в том числе
  общим лимитом. Роль проверяется по БД. Его фактический расход учитывается в счётчиках,
  поэтому он может исчерпать общий бюджет для обычных пользователей. Квота Cloudflare
  и технические ограничения размера/длительности файлов продолжают действовать.
- Сутки — UTC. Счётчики хранятся в PostgreSQL, резервируются атомарно, не сбрасываются
  перезапуском backend. Нулевой/отрицательный лимит минут запрещает запросы обычным пользователям.
- Попытка вызова Cloudflare учитывается даже при ошибке: провайдер мог обработать звук
  до разрыва связи. Автоматических повторов нет.

Это ограничения приложения, а не гарантия попадания в бесплатную квоту Cloudflare:
она общая с другими моделями аккаунта. Статистику смотреть в Workers AI dashboard.
На бесплатном плане Cloudflare при исчерпании квоты запросы отклоняются.

## Проверка

Войти в веб, открыть голосовое на русском, нажать «Расшифровать», подтвердить отправку.
Текст появится под волной. Повторно открыть то же голосовое в этой вкладке — результат
берётся из памяти без повторного обращения к Cloudflare.
Если ключей нет, кнопка скрыта; при ошибке или лимите показывается сообщение и возможность
повторить вручную. Отдельный React Native клиент требует отдельного подключения. Одновременно один процесс
backend декодирует не больше двух записей.

## Записи встреч в рабочих Звёздах

У сохранённой записи со звуковой дорожкой есть «Расшифровать встречу». После подтверждения
отправки звука в Cloudflare сервер ставит задание в очередь. Скачивать запись на устройство
не нужно. Обработка идёт в фоне, вкладку можно закрыть. В интерфейсе видны очередь,
подготовка и сколько минут обработано; готовый или частичный текст можно открыть и скачать `.txt`.
В тексте стоят отметки начала каждой пятиминутной части. Разделения по участникам нет.

Максимум — 4 часа и 512 МБ исходного звука, как у самих записей. Сервер декодирует звук
в моно FLAC 16 кГц и последовательно отправляет части до 5 минут в тот же Whisper Turbo
с русским языком. На подготовку требуется ffmpeg/ffprobe и минимум 512 МБ временного
свободного места. Временный FLAC удаляется после обработки или ошибки.

**Текст встречи сохраняется на сервере**, в отличие от расшифровки личного голосового.
Он общий для записи, доступен с других устройств и тем же людям, которым доступен
исходный звуковой файл: учитываются этажи, закрытые комнаты и гостевые пропуски.
При каждой загрузке текста и перед очередной частью сервер заново проверяет доступ.
Текст удаляется вместе с истечением 90-дневного срока записи. Удаление исходной записи
или её сообщения закрывает доступ к тексту. Повторные нажатия создают одно задание
на запись; уже готовый результат возвращается без обращения к Cloudflare.

Минуты расходуются из тех же суточных лимитов: 100 на запускающего и 180 на весь Quazar
по умолчанию. При исчерпании лимита или ошибке Cloudflare очередь останавливает эту
запись и сохраняет полученный текст. «Продолжить расшифровку» возобновляет её с первой
несохранённой части; новый запросивший расходует уже свои минуты. Автоматического
повтора ошибочных вызовов нет. Суперпользователь освобождён от этих ограничений Quazar;
его роль заново проверяется перед каждой платной частью. Квота Cloudflare остаётся общей.

На уже настроенном сервере заменить прежнее значение в `.env.prod` на
`TRANSCRIPTION_USER_MINUTES_PER_DAY=100` и пересоздать backend: явно заданное значение
окружения имеет приоритет над новым значением по умолчанию в коде.

Таблица `recording_transcripts` создаётся при старте backend. Фоновая очередь стартует
вместе с приложением и восстанавливает задания `queued`/`running` после перезапуска.
Блокировка PostgreSQL не позволяет двум процессам одновременно обрабатывать одну запись.
Каждая успешная часть сохраняется отдельно. Если процесс упал между ответом Cloudflare
и сохранением части, при восстановлении эта часть может потребовать повторного платного вызова.
