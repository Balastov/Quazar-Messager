# Голос на Планетах (LiveKit)

Голосовые каналы Созвездия работают через медиасервер **LiveKit** (SFU): каждый участник
отправляет свой голос один раз на сервер, сервер раздаёт его остальным. Сквозного шифрования
в каналах Созвездия нет.

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| `livekit` (docker, profile `voice`) | `docker-compose.prod.yml` | медиасервер, образ `livekit/livekit-server:v1.13.7` |
| `/livekit/` в системном nginx | добавляется `remote-deploy.sh` | сигналинг (WebSocket) → `127.0.0.1:7880` |
| `7882/udp`, `7881/tcp` | открываются в фаерволе вручную | сам голос (UDP), запасной путь по TCP |
| coturn `3478` | уже настроен | ретранслятор для клиентов за строгим NAT |
| бэкенд | `app/api/voice.py`, `app/core/livekit.py`, `app/core/voice.py` | токены входа, вместимость, модерация, «кто где сидит» по вебхукам |

Комнаты создаёт только бэкенд (`auto_create: false`); потолок — 25 человек на Планету,
вместимость конкретной Планеты проверяет бэкенд при выдаче токена (токен живёт 2 минуты).

## Что делает деплой автоматически

`deploy/scripts/render-livekit-config.sh`:
1. если в `.env.prod` нет `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET` — генерирует их (один раз);
2. собирает `deploy/livekit/livekit.yaml` (в git не попадает): публичный IP из `TURN_EXTERNAL_IP`,
   TURN из `WEBRTC_TURN_*`.

Если шаг не удался, сайт деплоится без голоса, а в логе деплоя будет `WARN: LiveKit config failed`.

## Что нужно сделать руками (один раз)

Открыть порты **7881/tcp** и **7882/udp**:
- в панели хостинга (группа безопасности / фаервол облака);
- в фаерволе самого сервера, если он включён:

```bash
sudo ufw status            # если "Status: active":
sudo ufw allow 7881/tcp
sudo ufw allow 7882/udp
```

## Проверка

```bash
curl -s https://quazar-msg.ru/livekit/          # должно ответить OK
cd /opt/quazar && docker compose -f docker-compose.prod.yml --env-file .env.prod --profile voice ps livekit
docker compose -f docker-compose.prod.yml --env-file .env.prod --profile voice logs --tail=50 livekit
```

С компьютера (не с сервера) — что UDP-порт доступен извне, проще всего проверить делом:
зайти на Планету с двух устройств из разных сетей (например, телефон через мобильный интернет).

## Если не слышно друг друга

- В браузере видно «Подключаемся…» и ошибка — порты 7881/7882 закрыты в панели хостинга.
- Подключились, но тишина — нажмите «Нажмите, чтобы слышать собеседников» (браузер блокирует
  звук без нажатия) и проверьте, что у собеседника не выключен микрофон.
- Ошибка «Голосовая связь на Планетах пока не настроена на сервере» — в `.env.prod` нет ключей
  LiveKit; смотрите лог деплоя.
