# Видеозвонки 1:1 (часть 3)

В web уже работают **аудио** и **видео** звонки по одному протоколу (`media: { audio, video }`).

## Что умеет клиент

- Кнопка видео в шапке чата, во вкладке «Звонки» и в панели собеседника
- Полноэкранное видео собеседника + своё в PiP
- Mic / камера on-off / Flip (передняя ↔ задняя)
- Push «Входящий видеозвонок», если настроена часть 2

## Проверка

1. Два аккаунта, оба разрешили камеру и микрофон  
2. Видеокнопка → принять на втором устройстве  
3. Проверить mute, выкл. камеры, Flip на телефоне  

TURN (часть 1) особенно важен для видео за NAT / LTE.
